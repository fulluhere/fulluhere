### 💡 Featured Projects

#### 1. DoCode – Online Judge & Competitive Programming Platform

A full-stack online judge platform with a microservices-oriented architecture for authentication, problem management and code execution.

**Key Technologies:**
- Frontend: React, Vite, Monaco Editor
- Backend: Node.js, Express.js, MongoDB
- Code Execution: Docker, Redis, BullMQ
- Authentication: JWT

**Key Features:**
- User authentication and problem management.
- Multi-language code execution supporting C++, Python, Java and JavaScript.
- Automated test-case evaluation and submission tracking.
- Asynchronous code execution using Redis and BullMQ.
- AI-powered hints for programming problems.

**Repositories:**
- [DoCode Auth](https://github.com/fulluhere/docode-auth)
- [Online Compiler Backend](https://github.com/fulluhere/online-compiler-backend)

#### 2. AI Interviewer – AI-Powered Interview & Assessment Platform

An AI-powered interview platform combining full-stack development with Large Language Models and Retrieval-Augmented Generation to support intelligent interview experiences.

**Key Technologies:**
- Frontend: React
- Backend: Node.js, Express.js, MongoDB
- AI Service: Python, FastAPI
- LLM: Ollama, Qwen2.5:3B
- AI Framework: LangChain
- Concepts: LLM Integration, RAG, NLP and Semantic Retrieval

**Key Features:**
- LLM-powered interview question generation.
- Integration of locally hosted language models using Ollama.
- Python-based AI microservice using FastAPI.
- LangChain-based LLM application workflows.
- Retrieval-Augmented Generation for context-aware responses.
- AI-assisted interview assessment and feedback.

#### 3. CountOn – Event-Driven Expectation Monitoring Platform

A collaborative full-stack project that tracks user-defined expectations, ingests real-world evidence and evaluates claims through a deterministic evaluation engine.

**Key Technologies:**
- Backend: Python, FastAPI
- Database: PostgreSQL, SQLAlchemy, Alembic
- Frontend: Next.js, React, TypeScript
- Authentication: Supabase Auth, JWT
- Database Security: PostgreSQL Row-Level Security (RLS)

**Key Features:**
- Deterministic evidence evaluation using MATCH, MISMATCH and UNKNOWN outcomes.
- Idempotent evidence ingestion with duplicate-event prevention.
- JWT-based authentication and owner-scoped authorization.
- PostgreSQL Row-Level Security for multi-user data isolation.
- Transactional audit logging and request ID tracing.
- Database migrations, API rate limiting and health/readiness checks.
- Automated backend testing with 237 documented passing tests (October 2026).

**Repository:** [CountOn](https://github.com/fulluhere/CountOn)
