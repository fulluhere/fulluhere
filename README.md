### 🔨 Featured Project — DoCode

An online judge platform built with a microservices architecture:

| Service | Stack | Description |
|---|---|---|
| `docode-auth` | Node.js, Express, JWT, MongoDB | Authentication, problem CRUD, leaderboard, AI hint generation |
| `online-compiler-backend` | Node.js, BullMQ, Redis, Docker | Sandboxed code execution for C++, Python, Java, JS |
| Frontend | React, Vite, Monaco Editor | Problem list, code editor, live submission polling |
